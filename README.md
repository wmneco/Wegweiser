# Wegweiser

> **Pronunciation:** *Wegweiser* [ˈveːkˌvaɪzɐ] — "signpost/guide" (VAYK-vy-zer, stress on the first syllable)

## What
Wegweiser is a self-hosted URL shortener written in Go, designed for cloud-native environments.

## Why
Built for developers who want full control over their link infrastructure. Wegweiser is a practical project for exploring Go and cloud-native engineering — from the basics of containerization and 12-factor configuration all the way to scaling challenges like high-throughput redirect handling, caching strategies, and distributed deployments for large numbers of users.
